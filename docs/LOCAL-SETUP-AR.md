# تشغيل صنعة SANAA على جهازك — الموقع + الباك اند + الذكاء الاصطناعي

## الملف فيه إيه؟
- **الموقع (Front End)** و **الباك اند (كل الـ `/api/...` زي موديل SANAA)** في مشروع واحد، وبيشتغلوا مع بعض بأمر واحد.
- **قاعدة البيانات:** ملفات بنائها كاملة + البيانات التجريبية (640 طلب، 40 عميل، 22 منتج) في فولدر `supabase/migrations`.
- **الذكاء الاصطناعي:** يشتغل ببلاش على جهازك بـ **Ollama** (زي موديل SANAA الأصلي)، أو بمفتاح **OpenAI**.

## عندك طريقتين

| | الطريقة 1 — سريعة | الطريقة 2 — كله على جهازك |
|---|---|---|
| قاعدة البيانات | الأونلاين (نفس بيانات الموقع) | على جهازك |
| شاشات المصنع (مبيعات، تصنيع، مخزون، مالية...) | تشتغل | تشتغل |
| شات العميل، تتبع الطلب، المساعد الذكي، التوصيات | **لا** | تشتغل |
| محتاج تنزّل | Node.js | Node.js + Docker + Ollama |

> ليه الطريقة 1 ناقصة؟ شات العميل والتتبع والمساعد الذكي محتاجين "المفتاح السري" لقاعدة البيانات، وده مش متاح للتنزيل من Lovable Cloud. في الطريقة 2 قاعدة البيانات بتاعتك وبتطلعلك مفتاحها.
> **لو عايز كل الـ features: اعمل الطريقة 2.**

## أولاً: البرامج اللي هتنزلها (مرة واحدة بس)

1. **Node.js** نسخة 20 أو أحدث — من https://nodejs.org (اختار LTS).
   - اتأكد: افتح Terminal (في ويندوز: PowerShell) واكتب `node -v` ← لازم يطلع v20 أو أكبر.
2. **Docker Desktop** (للطريقة 2) — من https://www.docker.com/products/docker-desktop
   - بعد التسطيب افتحه وسيبه شغال (لازم الأيقونة تبقى خضرا).
3. **Ollama** (للذكاء الاصطناعي) — من https://ollama.com
   - بعد التسطيب اكتب في الـ Terminal:
     ```
     ollama pull qwen2.5:7b
     ```
     (حوالي 4.7 جيجا — محتاج جهاز فيه 16 جيجا رام. لو جهازك أضعف استخدم `qwen2.5:3b`.)
4. (اختياري) **VS Code** عشان تفتح الملفات — https://code.visualstudio.com

## ثانياً: فك الضغط والتسطيب

1. فك ضغط `sanaa-source-v2.zip` في أي مكان، مثلاً `C:\sanaa` أو `~/sanaa`.
2. افتح Terminal جوه الفولدر:
   ```
   cd C:\sanaa        (ويندوز)
   cd ~/sanaa         (ماك / لينكس)
   ```
3. نزّل المكتبات:
   ```
   npm install
   ```
   (أول مرة بتاخد دقيقة أو اتنين.)
4. اعمل ملف الإعدادات من النموذج:
   ```
   copy .env.example .env.local      (ويندوز)
   cp .env.example .env.local        (ماك / لينكس)
   ```
5. افتح `.env.local` وغيّر `JWT_SECRET` لأي كلام طويل عشوائي. ممكن تطلعه بالأمر ده:
   ```
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

## ثالثاً (ب): الطريقة 2 — كل حاجة على جهازك

1. اتأكد إن **Docker Desktop** مفتوح.
2. شغّل قاعدة البيانات (أول مرة بتنزل حوالي 2-3 جيجا وتاخد 5-10 دقايق):
   ```
   npx supabase start
   ```
   هتتبني لوحدها بكل الجداول والصلاحيات والبيانات التجريبية.
3. في الآخر هيطبعلك شوية سطور. خد منهم:
   - **API URL** (غالباً `http://127.0.0.1:54321`)
   - **Publishable key** (في النسخ القديمة اسمه `anon key`)
   - **Secret key** (في النسخ القديمة اسمه `service_role key`)
   لو قفلت الشاشة، اكتب `npx supabase status` وهيطلعهم تاني.
4. افتح `.env.local` وشيل علامة `#` من أول السطور دي وحط القيم:
   ```
   SUPABASE_URL=http://127.0.0.1:54321
   SUPABASE_PUBLISHABLE_KEY=<Publishable key>
   VITE_SUPABASE_URL=http://127.0.0.1:54321
   VITE_SUPABASE_PUBLISHABLE_KEY=<Publishable key>
   SUPABASE_SERVICE_ROLE_KEY=<Secret key>
   ```
5. اتأكد إن Ollama شغال (برنامج Ollama مفتوح، أو اكتب `ollama serve` في Terminal تاني).
6. شغّل الموقع والباك اند:
   ```
   npm run dev
   ```
7. افتح **http://localhost:8080**

### روابط مفيدة وانت شغال على جهازك
- لوحة قاعدة البيانات (تشوف الجداول وتعدل فيها): http://127.0.0.1:54323
- الإيميلات اللي الموقع بيبعتها (تأكيد الحساب / نسيت كلمة السر): http://127.0.0.1:54324

### أوامر هتحتاجها
| عايز | اكتب |
|---|---|
| توقف الموقع | `Ctrl + C` في الـ Terminal |
| توقف قاعدة البيانات | `npx supabase stop` |
| ترجّع قاعدة البيانات زي أول مرة (تمسح كل حاجة وترجع البيانات التجريبية) | `npx supabase db reset` |
| تشغّل الاختبارات | `npm test` |

## رابعاً: اتأكد إن كل حاجة شغالة
افتح الروابط دي في المتصفح:
- http://localhost:8080/api/health ← لازم يطلع `"status":"ok"` (الباك اند شغال)
- http://localhost:8080/api/health/database ← لازم يطلع ok (قاعدة البيانات — الطريقة 2 بس)
- http://localhost:8080/api/health/ai ← لازم يطلع `"reachable":true` و `"model_installed":true` (الذكاء الاصطناعي)

## خامساً: جرّبه كصاحب شركة
1. افتح http://localhost:8080/dashboard ← "أنشئ حساباً" ← اسمك وإيميل وكلمة سر.
   - **في الطريقة 2: أول حساب تعمله بيبقى صاحب المصنع** (مدير + مسؤول المنصة). أي حساب بعده بيبقى موظف.
   - لو طلب تأكيد الإيميل، افتح http://127.0.0.1:54324 واضغط الرابط.
2. اختار **مدير المصنع** وجرّب: نظرة عامة ← المبيعات (طلب جديد والسعر بيتحسب لوحده بالضريبة 14%) ← الهندسة (التصميم 3D) ← المخزون ← التصنيع ← الجودة والتسليم ← المالية ← الموافقات.
3. **المساعد الذكي:** اسأل "إيه أكتر منتج اتباع الشهر ده؟" أو "مين العملاء اللي عليهم فلوس؟".
4. **إدارة المنصة:** المصانع والمستخدمين والخطط والإعلانات.
5. **موظف:** اعمل حساب تاني بإيميل تاني في نافذة تصفح خفي.

## سادساً: جرّبه كعميل (من غير حساب)
- **عرض سعر وتصميم:** http://localhost:8080/chat ← اكتب "عايز كنبة 3 مقاعد 220 في 90 خشب زان لون بيج" ← جاوب على الأسئلة ← اكتب "نعم" ← هيطلع عرض السعر والتصميم 3D.
- **تتبع طلب:** http://localhost:8080/track ← رقم العميل **15** ورقم الطلب **SO-0639**.

## سابعاً: اختيار الذكاء الاصطناعي (في `.env.local`)
| الاختيار | تكتب إيه | ملاحظات |
|---|---|---|
| **Ollama** (ببلاش، من غير نت) | `AI_BASE_URL=http://localhost:11434/v1` و `AI_CHAT_MODEL=qwen2.5:7b` | ده الافتراضي. الصوت (الميكروفون والقراءة بصوت) مش بيشتغل معاه |
| **OpenAI** (بفلوس، أدق) | `AI_BASE_URL=https://api.openai.com/v1` و `AI_API_KEY=sk-...` و `AI_CHAT_MODEL=gpt-4o-mini` | الصوت بيشتغل |
| **Lovable AI** (زي الموقع الأونلاين) | امسح سطر `AI_BASE_URL` وحط `LOVABLE_API_KEY=...` | |

بعد أي تغيير في `.env.local` وقّف الموقع (`Ctrl + C`) وشغله تاني (`npm run dev`).
لو الذكاء الاصطناعي وقع أو بطيء، الموقع بيرد بإجابات جاهزة بدل ما يقف.

## ثامناً: لو هتربط تطبيق موبايل
- كل الـ endpoints زي الموديل: `http://localhost:8080/api/...` (القائمة في README.md).
- **من موبايل حقيقي على نفس الواي فاي:** استخدم IP الكمبيوتر بدل localhost، مثلاً `http://192.168.1.10:8080/api/health` (اعرف الـ IP بـ `ipconfig` في ويندوز أو `ifconfig` في ماك).
- **من محاكي أندرويد:** `http://10.0.2.2:8080/api/...`
- دخول الموظفين: `POST /api/v1/auth/login` وبعدين ابعت الـ token في `Authorization: Bearer ...`
- دخول العميل: `POST /api/customer/auth/login`

## مشاكل ممكن تقابلك
| المشكلة | الحل |
|---|---|
| `npm install` طلّع error | اكتب `npm install --legacy-peer-deps` |
| `port 8080 is in use` | `npm run dev -- --port 3000` وافتح http://localhost:3000 |
| `Missing ... SUPABASE_SERVICE_ROLE_KEY` | انت على الطريقة 1 — الميزة دي محتاجة الطريقة 2 |
| `docker: command not found` أو `Cannot connect to the Docker daemon` | افتح Docker Desktop واستنى لحد ما يخضر |
| `/api/health/ai` بيقول `reachable: false` | افتح برنامج Ollama، واتأكد إنك عملت `ollama pull qwen2.5:7b` |
| `model_installed: false` | اسم الموديل في `AI_CHAT_MODEL` مش زي اللي نزلته — اكتب `ollama list` وشوف الاسم |
| الموقع فاضي أو شاشة بيضا | وقّفه وشغّله تاني، وافتح http://localhost:8080 مش https |
| عدّلت `.env.local` ومحصلش حاجة | لازم توقف `npm run dev` وتشغله تاني |
